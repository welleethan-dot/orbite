# Orbite

Jeu d'arcade mobile à une touche : votre sonde tourne autour d'une planète, un toucher la fait changer d'orbite. Évitez les astéroïdes, attrapez les éclats.

## Jouer

Ouvrez le jeu dans Safari sur iPhone (ou Chrome sur Android), puis **Partager → Sur l'écran d'accueil** pour l'installer comme une application. Il fonctionne ensuite hors connexion.

## Fichiers

- `index.html` : le jeu complet (HTML, CSS et JavaScript, sans dépendance)
- `manifest.webmanifest` : nom, icônes et affichage plein écran de l'application
- `sw.js` : mode hors ligne (augmentez `CACHE` à chaque nouvelle version)
- `icons/` : icônes de l'application
